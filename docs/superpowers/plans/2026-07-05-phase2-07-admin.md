# Phase 2 — Plan 07: Admin & Editing (관리·편집·리포트·하드닝) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 관리 화면 CRUD(택소노미·유저/역할·프로파일·저장 백엔드) + 프로파일 스키마 기반 메타데이터 편집 폼 + Binder 리포트 8종(CSV 포함)을 구현하고, Plan 04/05/06 하드닝 백로그를 청산한다.

**Architecture:** 모든 브라우저발 변경은 Server Action(+useActionState) — 상태 변경 API 라우트 추가 없음(리포트는 읽기 전용 GET). db 계층에 update/CRUD 쿼리 신설(트랜잭션 + writeAudit + buildNodeSearchDocs), 검증은 기존 Ajv `validateDescriptive`가 단일 진실원. 리포트는 순수 SQL(GROUPING SETS·LATERAL·window 누적합) → 서버 컴포넌트 테이블 + CSV 스트림.

**Tech Stack:** 기존 스택 그대로 — **신규 런타임 의존성 0개**. (설계서 §6의 react-hook-form+Zod 언급은 채택하지 않음: 프로파일 검증의 SoT가 이미 Ajv JSON Schema이고 Zod 병행은 검증 로직 이중화라 Server Action+Ajv로 대체. 클라이언트 즉시검증은 후속 확장점. — 승인된 편차)

## Global Constraints

- import 규칙(BINDING): `packages/db/src/schema/*.ts` 상호 import만 확장자 없음; 그 외 상대 import는 `.js`. 클라이언트 컴포넌트에서 `@binder/core` 배럴 금지(`@binder/core/i18n`만), `@binder/db`는 type-only. 서버 컴포넌트/액션은 배럴 자유.
- CSRF 불변식(Plan 06 확립): 쿠키 인증 상태 변경 라우트 0개 유지. 이 계획의 모든 변경은 Server Action. 신규 API 라우트는 읽기 전용 GET(`withAuth`)만.
- 감사(audit): 모든 신설 mutation은 `writeAudit` 필수 — update는 before/after + `jsonbTopLevel`, delete는 snapshot. **insert는 이벤트 행만 기록된다**(writeAudit은 insert에서 changes/snapshot을 저장하지 않음 — after 페이로드를 넘겨도 무시되므로 넘기지 말 것). **users 행은 `passwordHash`를 before/after/snapshot에서 제거하고 변경 시 `{ passwordHash: ['[REDACTED]', '[REDACTED]'] }`가 아니라 키 자체를 빼고 `password_changed: [false, true]` 류 마커 필드로 기록**(Task 6에 정확한 코드).
- 권한 문자열: 관리 화면 = `admin:manage`(admin의 `'*'`만 충족 — 시드 변경 없음), 편집 폼 = `records:write`, 본인 비밀번호 변경 = 인증만. `hasPermission(perms, x)` 사용.
- 소프트델리트/유니크 규칙 유지: nodes 계열은 partial unique(live). terms는 deleted_at 없음 → **하드 삭제 + 사용처 가드**(사용 중이면 `TermInUseError`).

```ts
// Pre-computed hash of a throwaway password: verified when the user is NOT found so that
// unknown-email and wrong-password take the same time (timing side-channel hardening).
let dummyHash: string | null = null;
async function getDummyHash(): Promise<string> {
  if (!dummyHash) dummyHash = await hashPassword('binder-dummy-timing-password');
  return dummyHash;
}

export async function authenticate(db: PostgresJsDatabase, email: string, password: string) {
  const [u] = await db.select().from(users).where(and(eq(users.email, email), eq(users.active, true)));
  if (!u) {
    await verifyPassword(await getDummyHash(), password);
    return null;
  }
  return (await verifyPassword(u.passwordHash, password)) ? { userId: u.id } : null;
}
```

`packages/db/src/queries/users.ts` (신규):

```ts
import { and, eq, ne } from 'drizzle-orm';
import { createHash } from 'node:crypto';
import type { PostgresJsDatabase } from 'drizzle-orm/postgres-js';
import { hashPassword, verifyPassword } from '@binder/core';
import { sessions, users } from '../schema/index.js';
import { writeAudit } from './audit.js';

function hashToken(raw: string): string {
  return createHash('sha256').update(raw).digest('hex');
}

export async function destroyUserSessions(
  db: PostgresJsDatabase, userId: number, keepRawToken?: string,
): Promise<number> {
  const where = keepRawToken
    ? and(eq(sessions.userId, userId), ne(sessions.id, hashToken(keepRawToken)))
    : eq(sessions.userId, userId);
  const rows = await db.delete(sessions).where(where).returning({ id: sessions.id });
  return rows.length;
}

export async function changePassword(
  db: PostgresJsDatabase,
  input: { userId: number; currentPassword: string; newPassword: string; keepSessionToken?: string },
): Promise<'ok' | 'wrong-password'> {
  const [u] = await db.select().from(users).where(eq(users.id, input.userId));
  if (!u || !(await verifyPassword(u.passwordHash, input.currentPassword))) return 'wrong-password';
  await db.update(users).set({ passwordHash: await hashPassword(input.newPassword) }).where(eq(users.id, input.userId));
  await destroyUserSessions(db, input.userId, input.keepSessionToken);
  await writeAudit(db, {
    tableName: 'users', rowId: input.userId, action: 'update', actorId: input.userId, origin: 'user',
    before: { password_changed: false }, after: { password_changed: true },   // hash NEVER enters audit
  });
  return 'ok';
}
```

```ts
      await registerFixityReport(db, { aipUuid: c.aip_uuid, success: outcome === 'ok', message: message || undefined, failures: fx, sessionUuid, startedAt, completedAt });
      if (outcome !== 'unreachable') {
        // definitive result: update verification bookkeeping; transient errors must NOT flip status
        await db.execute(sql`
          UPDATE aip_copies SET last_verified_at = ${completedAt}, status = ${outcome === 'ok' ? 'ok' : 'lost'}::copy_status
          WHERE id = ${c.copy_id}
        `);
      }
      scanned += 1;
      if (outcome === 'failed') { failed += 1; failures.push({ aipUuid: c.aip_uuid, message }); }
      if (outcome === 'unreachable') { unreachable += 1; failures.push({ aipUuid: c.aip_uuid, message }); }
    }
```

```ts
  constructor(field: 'accessionNumber' | 'componentNumber') {

export async function updateNode(
  db: PostgresJsDatabase, id: number, patch: UpdateNodePatch, actorId: number | null,
): Promise<NodeRow> {
  const updated = await db.transaction(async (tx) => {
    const [before] = await tx.select().from(nodes).where(and(eq(nodes.id, id), isNull(nodes.deletedAt)));
    if (!before) throw new Error(`node not found or deleted: ${id}`);
    const set: Record<string, unknown> = { updatedAt: new Date() };
    for (const k of ['title','identifier','accessionNumber','componentNumber','departmentTermId','dateCreated','descriptive','sourceAttributes','sourceCulture'] as const) {
      if (k in patch) set[k] = patch[k];
    }
    let after;
    try {
      [after] = await tx.update(nodes).set(set).where(eq(nodes.id, id)).returning();
    } catch (err) {
      // postgres-js error shape precedent: isAipUuidUniqueViolation in aips.ts (code check first,
      // constraint_name with message fallback). Real index names: nodes_accession_live_uq / nodes_component_number_live_uq.
      const c = err as { code?: string; constraint_name?: string; message?: string };
      if (c.code !== '23505') throw err;
      const sig = `${c.constraint_name ?? ''} ${c.message ?? ''}`;
      if (sig.includes('accession')) throw new DuplicateIdentifierError('accessionNumber');
      if (sig.includes('component_number')) throw new DuplicateIdentifierError('componentNumber');
      throw err;
    }
    await writeAudit(tx, {
      tableName: 'nodes', rowId: id, action: 'update', actorId, origin: 'user',
      before: before as unknown as Record<string, unknown>,
      after: after as unknown as Record<string, unknown>,
      jsonbTopLevel: ['title', 'descriptive'],
    });
    return after;
  });
  // search docs are a rebuildable projection — rebuilt OUTSIDE the tx (freshness contract in search.ts)
  await buildNodeSearchDocs(db, id);
  return updated as NodeRow;
}
```

```ts
const compiled = new Map<string, ReturnType<typeof ajv.compile>>();

export function validateDescriptive(fieldSchema: object, payload: unknown, cacheKey?: string) {
  let validate;
  if (cacheKey) {
    validate = compiled.get(cacheKey);
    if (!validate) {
      if (compiled.size >= 100) compiled.clear();   // bounded; LRU overkill at this scale
      validate = ajv.compile(fieldSchema);
      compiled.set(cacheKey, validate);
    }
  } else {
    validate = ajv.compile(fieldSchema);
  }
  const valid = validate(payload) as boolean;
  const errors = (validate.errors ?? []).map((e: { instancePath: string; message?: string }) =>
    `${e.instancePath || '(root)'} ${e.message ?? ''}`.trim());
  return { valid, errors };
}
```
