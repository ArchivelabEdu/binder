**Goal:** 모노레포 내 **별도 앱 apps/search** — Binder 변경 피드를 구독해 그래프+벡터(pgvector) 인덱스를 증분 유지하고, 자연어 질의를 하이브리드 검색(그래프 탐색+벡터)→re-rank→근거 인용 답변으로 처리(OG-RAG 축약), 근거에서 Binder 원본으로 점프. 시연: "백남준 작품 중 CRT 모니터를 쓰는 것은?"

**Architecture (D5):** apps/search는 Binder와 **변경 피드·JSON-LD로만 결합**(@binder/* import 전면 금지). 저장은 동일 PG 인스턴스의 전용 스키마 `search`(자체 drizzle 스키마+**분리 저널**). 임베딩·답변 LLM은 인터페이스 주입 — FakeEmbedder(결정적 문자 n-gram)+AnthropicAnswerer(실키 확보됨)/FakeAnswerer(e2e 기본). 색인 실행은 v1 인라인(관리 버튼).

**Tech Stack:** Next 15(:3200), drizzle+pgSchema('search'), pgvector(이미지 스왑), @xyflow/react, @anthropic-ai/sdk, Playwright 이중 webServer.
